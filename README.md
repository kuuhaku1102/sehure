# TOREKAMAFIA 山口店 公式サイト テーマ

トレカ買取専門店「トレカマフィア山口店」のための WordPress テーマです。
近未来 / サイバー系のデザインに、豊富なアニメーションとローカルSEO最適化を組み込み、
**管理画面から専門知識なしで更新できる**構成にしています。

---

## 1. 初期セットアップ（最初に一度だけ）

1. このフォルダごと `wp-content/themes/torekamafia-yamaguchi/` にアップロード
2. **管理画面 → 外観 → テーマ** で「**TOREKAMAFIA Yamaguchi**」を有効化
3. **設定 → 表示設定 → ホームページの表示** を「固定ページ」にし、
   ホームページに空の固定ページ（例:「トップ」）を割り当てると `front-page.php` がトップに表示されます
   （※固定ページを割り当てなくてもトップは表示されます）
4. **設定 → パーマリンク** を開いて「変更を保存」を一度クリック（カスタム投稿のURLを有効化）

---

## 2. 店舗情報・キャッチコピーの編集

**外観 → カスタマイズ → ★ サイト設定（トレカマフィア）** から、コードを触らず編集できます。

| セクション | 編集できる内容 |
| --- | --- |
| **店舗基本情報** | 店舗名 / 電話 / 住所 / 営業時間 / 定休日 / LINE・X・Instagram URL / Googleマップ |
| **ヒーロー（トップ最上部）** | キャッチコピー・サブコピー・CTAボタンの文言とリンク・背景画像 |
| **実績カウンター** | トップの数字（買取率・査定スピードなど）3項目 |
| **SEO設定** | メタディスクリプション / OGP画像（SNSシェア画像） |

### ロゴの設定
**外観 → カスタマイズ → サイト基本情報（Site Identity） → ロゴを選択**
から、トレカマフィアのロゴ画像をアップロードするとヘッダーに表示されます。
※ 背景が透過した **PNG（背景透明）** を推奨します（サイトが暗い背景のため）。
　同じ画像を「サイトアイコン」に設定すると、ブラウザのタブ用アイコンにもなります。

### Googleマップの入れ方
Googleマップで店舗を検索 → **共有 → 地図を埋め込む → HTMLをコピー** →
`src="..."` の **URL部分だけ**を「Googleマップ 埋め込みURL」に貼り付けます。

---

## 3. お知らせ・イベントの追加

**管理画面 左メニュー → お知らせ・イベント → 新規追加**

- タイトルと本文を書くだけ。ブログと同じ感覚で投稿できます。
- アイキャッチ画像を設定すると一覧が華やかになります。
- 公開するとトップページの「お知らせ」欄に自動で新しい順に表示されます。

---

## 4. 強化買取カードの追加（画像＋買取価格）

**管理画面 左メニュー → 強化買取カード → 新規追加**

1. **タイトル** … カード名（例：リザードン SAR）
2. **アイキャッチ画像** … カード画像
3. 右側の「**買取情報**」ボックス
   - **買取価格（円）** … 数字のみ入力（空欄なら「要査定」と表示）
   - **バッジ表記** … 「買取強化中」「UP」など（任意）
   - **補足メモ** … 「PSA10」「美品」など（任意）
4. **買取カテゴリー**（右側）… 「PSA10」または「未開封BOX」にチェック
5. 「並び順」を数字で指定すると表示順を調整できます（小さいほど先頭）

→ トップの「強化買取カード」と、買取一覧ページに自動で反映されます。

---

## 5. メニュー（ヘッダー / フッター）

**外観 → メニュー** で作成し、位置を「ヘッダーメニュー」「フッターメニュー」に割り当てられます。
未設定の場合はトップページの各セクションへのリンクが自動表示されます。

---

## 6. SEOについて（実装済み）

- タイトルタグ / メタディスクリプション / OGP・Twitterカードを自動出力
- **LocalBusiness（店舗）構造化データ**を出力（Google のローカル検索・マップ対策に有効）
- パンくずリストの構造化データ
- 見出し構造・レスポンシブ・表示速度に配慮した軽量な自作アニメーション

> さらに強化したい場合は、無料プラグイン「XML Sitemap Generator」等でサイトマップ送信、
> Google ビジネスプロフィールの登録を推奨します。

---

```
single.php        記事（お知らせ）詳細
archive.php       お知らせ一覧・強化買取カード一覧
page.php          固定ページ
404.php           404ページ
header.php / footer.php
style.css         デザイン
assets/js/main.js アニメーション
```
